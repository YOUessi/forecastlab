# Agent 1–2 产品局限

本说明用于解释问题确认、证据发现及其下游用途的适用边界。接口和数据流见 [集成说明](integration.md)，请求示例见 [API 说明](api.md)。

## 1. 引用可追溯不等于事实或推理已证实

快照哈希、段落、逐字 quote 和字符偏移用于核对保存的文本与引用是否一致，不能证明原来源真实、一手来源权威、内容完整或作者判断正确。

claim 边界校验覆盖常见的数字、日期、实体和来源元数据越界，但不是通用语义蕴含验证器。指代不明、范围变化、因果加强、语气变化和跨语言释义仍可能产生错误；`findings_validated` 不表示已经由人工或独立模型确认语义正确。提示词中的保守表达要求也不能作为质量测量结果。

来源、发现、用户前提和建模假设需分别阅读。用户保留 P 表示认可其问题含义；将 P 指定为情景条件表示要求在该条件下推演，两者都不等于确认事实为真。未找到反证也不能证明原观点成立。

相关实现：[原文校验](../../backend/app/provenance.py)、[发现边界](../../backend/app/agents/evidence.py)、[下游引用规则](../../backend/app/graph.py)。

## 2. 检索覆盖、来源分组与历史截点

在线取证依赖 Brave 或 Tavily 的返回内容。搜索摘要不能视为正文，服务商未返回的内容不会进入快照。系统没有通用的动态网页或登录资料浏览流程，不能保证完整召回、正文抓取或覆盖所有相反解释。

快照正文最多保留 200,000 个 Unicode 码点，截断会标记。传入模型的段落另受上下文预算限制，并采用词项重叠选择相关段落，可能遗漏间接相关内容或必要上下文。保留了完整快照也不等于模型读取了全文。

精确重复项可合并，明确转载线索和高文本重叠可用于分组或提示；这些规则不能认证来源独立性。相同域名不等于同一源头，不同域名也不等于独立佐证。导入者声明的一手来源身份或分组依据仍需核查，质量概览的数量不能替代这项判断。

发布时间未知时保持未知；缺少时区的可解析日期按 UTC 记录并注明依据。今天取得且标注较早发布日期的网页，不能自动证明当时版本的内容相同。`live_near_cutoff` 描述近实时取证条件，不是历史冻结证明；`historical_exercise` 表示历史练习。严格盲回测需要可核验的截至日前材料及相应评估设计。

未来结算结果尚未发生属于预测的不确定性，不能据此认定截至日证据缺失；但它也不能被提前作为已发生事实引用。

相关实现：[来源处理](../../backend/app/sources.py)、[段落选择](../../backend/app/provenance.py)、[质量概览](../../backend/app/evidence_quality.py)。

## 3. 教学演示、模型判断与预测质量

固定教学模式使用预制响应和虚构材料，适合检查界面、确认、存储和引用流程，不能用于测量真实模型的前提识别、证据支持、检索质量或预测准确率。

多个 Agent 使用同类模型时可能出现相关错误；角色分工和一致意见不增加外部证据。质量概览只描述取证状态，不能直接换算为概率或作为事实可信度认证。世界状态、主体行动和模拟步骤都是带条件的模型输出。

当前产品没有把研究性语义 judge 作为生产发现的强制准入门槛。结构校验、软件测试或某个冻结数据集上的结果，均不能单独证明真实场景中的语义正确率或概率校准。质量主张需要明确数据、模型、人工标注方式、独立性、失败样本与适用范围；不能从教学输出或提示词推导百分比。

相关实现：[固定教学数据](../../backend/app/agent12_demo.py)、[Agent 2](../../backend/app/agents/evidence.py)、[完整工作流](../../backend/app/graph.py)。

## 4. 运行恢复与用量记录

模型调用和搜索都有预算限制。新版运行恢复时沿用已保存状态和消耗；已经开始但未保存结果的搜索批次不会在同一运行内自动重发，重新取证需创建新运行。

进程中断可能使已发出请求的 token 用量或准确耗时无法恢复，这些值不能作为完整账单。准备和运行记录汇总时需按 `request_id` 去重，并核对服务方计费。远端模型即使使用固定温度，也不保证跨时间逐字一致，来源网页和服务可用性也可能变化。

相关实现：[请求记录与预算](../../backend/app/llm.py)、[恢复](../../backend/app/graph.py)、[持久化](../../backend/app/storage.py)。

## 5. 部署边界

服务没有内置用户认证、租户隔离或分布式任务队列，运行中的并发控制依赖进程内状态。适合单用户、单 worker 使用；不能把启动多个 worker 视为已经支持多用户隔离或分布式执行。

`scripts/start-local.sh` 绑定本机环回地址。需要对外提供访问时，应按实际部署环境配置访问控制、网络边界和运行数据权限。快照路径校验只限制文件读取方式，不代替用户身份与访问权限管理。

相关说明：[服务器部署](../server-deployment.md)、[启动脚本](../../scripts/start-local.sh)、[服务接口](../../backend/app/api.py)。
