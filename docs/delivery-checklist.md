# 课程交付清单

本文件记录尚需小组执行的工作，不代表已经取得实验结果。

## 真实验证

- [ ] 配置 DeepSeek Key，用至少三个不同领域的真实问题各跑通一次。
- [ ] 配置 Tavily Key，抽查在线来源的原文、日期与引用支持度。
- [ ] 收集 20–30 个问题，按事件分组划分调试与固定测试集。
- [ ] 固定模型、提示词、预算和证据包后运行完整框架与单 Agent 基线。
- [ ] 记录覆盖率、引用支持率、Brier、耗时、token，以及失败和拒答样例。
- [ ] 找 3–5 名同学完成依据查找、假设识别和结论解释任务。

## 报告与展示

- [ ] 5–8 页报告：问题、系统、方法、实验、局限、引用、贡献与 LLM 使用披露。
- [ ] 10 分钟展示：问题 2 分钟，架构 2 分钟，演示 3 分钟，实验 2 分钟，局限 1 分钟。
- [ ] 准备真实运行录屏作为网络或模型故障后备；历史回放明确标记时间。
- [ ] 按 Moodle 核对提交日期和正式格式要求。
